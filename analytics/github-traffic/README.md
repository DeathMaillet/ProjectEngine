# GitHub traffic archive

Daily long-term archive of repository traffic.

GitHub exposes repository views and clones only for a rolling 14-day window. This workflow snapshots the traffic API every day and keeps the history in Git.

Files:
- `daily_views.csv`
- `daily_clones.csv`
- `referrers_history.csv`
- `popular_paths_history.csv`
- `raw/YYYY-MM-DD.json`

The workflow can also be run manually from the GitHub Actions tab.
