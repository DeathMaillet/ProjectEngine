PRIVACY & AUDIENCE MEASUREMENT

Aggregate statistics, not personal tracking.

ProjectEngine uses Cloudflare Web Analytics only to understand aggregate website traffic and page performance.

What is measured

  • Aggregate page views and visits
  • Referring websites and visited pages
  • General browser, operating system and device categories
  • Approximate country-level traffic
  • Page-load and Core Web Vitals performance metrics
  • 404 pages, so broken links can be repaired

What is not used

  • No cookies
  • No local storage or persistent browser identifier
  • No fingerprinting
  • No cross-site or cross-device tracking
  • No advertising profile or behavioural targeting
  • No names, email addresses or GitHub identities

How the measurement works

Cloudflare Web Analytics uses a lightweight JavaScript beacon to collect aggregate page-view and performance information. Cloudflare states that Web Analytics does not collect or use visitors' personal data and does not track individual visitors across websites.

The beacon does not use cookies, localStorage or another persistent client-side identifier.

Purpose

These statistics are used only to improve the ProjectEngine website, understand which pages are useful, detect broken navigation and assess aggregate interest in the open-source project.

The information is not used for advertising, profiling or individual identification.

Blocking audience measurement

The site does not display a consent banner because it does not use analytics cookies or persistent visitor identifiers. Visitors who nevertheless prefer not to contribute to aggregate statistics can block requests to static.cloudflareinsights.com and cloudflareinsights.com using their browser or content blocker.

Contact

Questions about this website or its audience measurement can be raised through the ProjectEngine GitHub discussions.
